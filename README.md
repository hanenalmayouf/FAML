# FAML — أساسيات تعلم الآلة التطبيقية

عرض تدريبي عربي تفاعلي لدورة **Fundamental Applied Machine Learning**، ويشمل شرائح الدورة ودفاتر التطبيق العملية.

## التشغيل محليًا

```bash
npm install
npm run build
```

بعد ذلك افتح:

```text
public/index.html
```

## المحتوى

- اليوم الأول: خريطة تعلم الآلة وأنواع التعلم.
- اليوم الثاني: البيانات والمعالجة المسبقة وأول نموذج تصنيف، مع تطبيق K-Means.
- اليوم الثالث: التعلم الخاضع للإشراف والتقييم.
- اليوم الرابع: المشروع المتكامل.
- اليوم الخامس: عرض المشاريع وتقييمها.

دفاتر Jupyter موجودة داخل `public/downloads/`.
